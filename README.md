# GitHub 项目白话解读器

这是一个 Codex skill，帮助普通人看懂 GitHub 上的 skill、应用、工具和插件项目。它先提炼少数关键事实，再查证影响理解的陌生术语，并用日常语言解释这些术语在项目里具体指什么。

## 适用场景

- 看到一个 GitHub 仓库，不确定它究竟能做什么。
- 分辨某个项目是 AI skill、独立应用、插件、命令行工具，还是几种东西的组合。
- 安装前想弄清楚需要什么平台、账号、API key、权限、费用或技术准备。
- 遇到 MCP、API、CLI、反编译等术语，希望知道它们的日常含义，以及它们在这个项目中负责什么。
- 想比较几个相似仓库，了解它们的主要区别和适用对象。

## 它会怎么解释

- 先用一句话说明项目用途，再列出通常 3–5 个最影响判断的要点。
- 只解释真正妨碍理解的术语；优先查项目文档、官方平台说明和相关标准，并提供来源链接。
- 区分仓库的自我介绍、文件能证实的能力，以及目前无法确认的地方。
- 按需说明使用门槛、数据流向、权限、局限和项目状态，不用无关细节淹没重点。

## 使用示例

在 Codex 中输入：

```text
$github-project-explainer https://github.com/owner/repo
```

也可以补充你的关注点：

```text
$github-project-explainer https://github.com/owner/repo
假设我不懂编程，讲讲它能帮我做什么、要准备什么，并查证关键术语和权限风险。
```

比较项目时，可以一次提供多个仓库链接，并说明你最在意什么，例如“是否容易安装”“会不会读取我的文件”或“能不能在 Windows 使用”。

## 安装

在 Codex 中发送：

```text
用 $skill-installer 安装这个 GitHub 技能：
https://github.com/yycczq/github-project-explainer/tree/main/skills/github-project-explainer
```

安装后使用 `$github-project-explainer` 调用。其他支持 Agent Skills 的助手可按各自的方式安装；目前未逐一验证其他客户端。

## 使用边界

这个 skill 为了解释项目而阅读仓库文件和相关文档；它不会仅为了说明项目就运行代码、安装软件、授予权限或向项目服务发送数据。仓库内容会被当作待分析的材料，而不是需要遵循的指令。对来源没有证实的结论会标为未知或推断。

## 仓库简介建议

将 GitHub 上的 skill、应用、工具和插件项目提炼成普通人能理解的要点，并查证关键术语。
